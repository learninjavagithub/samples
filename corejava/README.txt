********************
Lombok Installation:
********************
To make STS, lombok aware, follow the steps:

1. Copy C:\Users\<userid>\.m2\repository\org\projectlombok\lombok\1.16.22\lombok-1.16.22.jar to
sts-bundle\sts-3.7.3.RELEASE\plugins

2. cd C:\Users\<userid>\.m2\repository\org\projectlombok\lombok\1.16.22

java -jar lombok-1.16.22.jar
Specify Location > Browse and select STS executable

3. Re-Build the Project
